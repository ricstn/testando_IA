## Pergunta 23
Defina "Despongar". Responda de forma objetiva.

### Resposta IA
Despongar é um processo de separação ou remoção de uma substância de outra, com o objetivo de obter uma mistura final contendo apenas a substância desponsada e outra substância contêiner.

A despongação pode ser realizada por meio de diferentes métodos, incluindo:

* Remoção química: utilizando agentes químicos para separar as substâncias.
* Filtração: utilizando fios de vidro ou outros materiais para separar as substâncias.
* Crystallização: utilizando reagentes químicos para formar cristais que sejam mais pesados do que a substância original.

A despongação é um processo comum em diversas áreas, incluindo:

* Química: para separar compostos orgânicos e inorgânicos.
* Bioquímica: para separar proteínas e outros componentes biológicos.
* Mecânica de fluidos: para separar substâncias de fluidos líquidos.

No contexto da química, a despongação é um processo fundamental para obter produtos finais com características específicas.
